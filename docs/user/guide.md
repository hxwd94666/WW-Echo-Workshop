# 声骸工坊使用指南

可在“声骸库 / 匹配 / 配装”切换；标题栏提供档案和设置。连接游戏只影响收录，已有库存可离线评分和配装。

> **Windows 安全提示**：插件包含未签名的本地计算程序，系统可能提示“打开这些文件可能会对你的计算机有害”。请右键 ZIP → 属性 → 勾选“解除锁定”，或在插件目录执行 `Get-ChildItem '...\echo-workshop' -Recurse | Unblock-File`；不要关闭 Defender。程序只在本机计算，不执行远程代码。

## 声骸库

打开游戏声骸背包或完整展示页后收录。扫描前回到背包顶部，扫描期间尽量不操作游戏；停止会保留已经收录的记录。

点击卡片可选择，选择声骸模式支持直接多选和全选当前结果；全选后按钮变为“清空”，点击清空全部勾选，包括筛选隐藏的项。打开、关闭、确认筛选和搜索只改变展示，不自动勾选。筛选中的同组多选取并集，不同筛选组同时满足；隐藏的已选项保留，取消选择返回原调用页。

卡片右键进行核对编辑、删除或快速评分。保护图标和筛选同时涵盖本地保护与配装预留；预留会注明角色。本地保护可在右键菜单设置，解除它不会释放其他角色的预留。所有保护只影响工坊记录，不修改游戏内锁定状态。

核对时检查名称、套装、COST、等级和词条，标记已核对后保存。原始截图只用于辅助核对。新收录保存同一识别帧的连续声骸详情裁剪图，保留名称、等级、COST、主副词条、套装与装备者的原始像素，不缩放、不叠加评分，也不保存OCR加速拼图。旧整屏截图保持原样；查看窗口按图片实际尺寸横纵滚动。

扫描失败不等于已入库待核对：查看失败位置后回游戏重新展示对应声骸，再手动收录或重新扫描，必须获取新画面。

## 手动收录与快捷键

手动模式点击“开始收录”只进入等待状态，不读取或保存当前声骸。未设置“收录当前声骸”快捷键时会弹窗，可直接“前往设置”。回到游戏前台按一次快捷键，只提交当前一件；完成后继续等待下一次快捷键。先在游戏前台取得至少三张新鲜采样，跨度至少0.6秒，再冻结最后一帧并只解析这份快照。采样完成前请保持声骸页面；提示“画面已冻结”后，切出游戏不再作废已取得的截图。逐框验证三张采样中的词条、名称和等级文本稳定后才保存；不在后台重抓其他声骸。采样期间切出、文本变化、超时、主动停止、档案或截图来源变化时不提交。

开始收录时会确保快捷键监听与事件桥就绪，无需先打开旧任务卡；重新打开页面或使用同一配置不会重置监听。设置 → 收录中直接显示监听状态及最近快捷操作结果；游戏评分浮层仍不展示这些反馈。

背包支持逐件手动收录和自动扫描；角色完整展示页（含左右对比时右侧选中件）支持手动收录；强化页信息不全，只评分，不收录。

“连续浏览收录”是另一项可选快捷操作：你手动切换声骸，程序自动保存稳定识别的当前件，不自动点击或翻页，也不要求每件按键。该快捷键开始、暂停或继续，停止快捷键结束。疑似重复或升级保留待确认，不静默覆盖。没有启用该连续模式时，仅浏览不会入库。

## 实时评分

连接游戏并启用实时评分后，支持背包、单件展示、左右对比与强化页面。对比页左右词条独立解析，以右侧所选角色模版计算两件声骸的当前分、理论最高分，并对两侧所有词条框选和显示副词条档位；手动收录只收录右侧选中声骸。

评分使用透明背景和描边文字，按模版数量调整字号与区域宽度：单模版更大，双模版适中，三模版紧凑；数值始终完整，窄区按空间适配。整个文字区与词条区垂直居中。背包、对比与展示页放在词条左侧，强化页放在词条右侧。当前评分和理论最高各占一行，不遮主副词条或底部操作按钮。

显示模版名、当前分与有效评级、理论最高分、词条框、副词条档位和逐词条贡献值。COST未直接识别（例如强化页）时标为“参考”，不显示确定评级。不显示评级门槛、权重版本、+25口径说明、识别疑问、收录状态或快捷键反馈；诊断和收录结果仍可在工坊内查看，校验规则未放宽。

开启“显示匹配角色评分”且当前档案的匹配页已选角色时，实时评分仅使用匹配页选择，最多三项；设置中的角色、模版和跟随装备角色暂时禁用，不混入第四项，也不覆盖原设置。关闭该开关或移除全部匹配角色后，恢复原设置。普通页面每个模版以名称、当前评分及评级、理论最高三行展示；强化页仍为参考评分，不显示确定评级。词条框、档位与逐词条贡献值仍显示。对比页每个模版用五行展示：名称、当前评分标题、左右数值、理论最高标题、左右数值。两侧所有词条保留框选与档位，不在边缘或汇总区另列贡献值。明确不适配时标注“不适配”；基础分不是自动配装推荐，也不代表队伍伤害排序。

## 评分与匹配

快速评分是单件声骸对一个角色/模版的评分。匹配可添加一个或多个角色，对一个或多个候选声骸比较当前评分及评级。

选择角色与候选后点击“开始计算”。编辑设置或资料更新会使旧结果过期，不自动重算。对比角色可在结果中切换，不重新计算。角色设置中的有效修改自动保存，包括COST、主词条、套装与固定件；无需额外确认。不完整输入或冲突要求会显示具体错误，修正后继续自动保存，不覆盖上次有效配置。固定声骸按物理UUID保存：固定槽只匹配指定声骸，其余声骸仍可匹配未固定槽；不会自动分配五件。

匹配只设置单件可生效的套装范围、COST、主词条和固定件；至少几件套装效果在配装中设置。快速评分衡量词条质量，明确不适配的声骸会提示；高分不等于符合主匹配的所有要求。

单件采用模版50制评分口径；界面显示当前分和评级，不把潜力当当前分。需要阈值时明确打开评级标准，无悬浮解释。

从匹配或配装进入“选择声骸”会返回原模式。“确定选择”使用全部勾选项（包括被筛选隐藏的项）；“使用筛选结果”只使用当前筛选可见集合，必须先设置搜索或至少一项筛选条件，无条件时请明确点“全选”再确定。隐藏的已选项存在时会显示数量，取消不改原候选。

## 配装

配装与匹配独立。下拉选择即加入角色，点击角色只切换查看，点击旁边的齿轮设置装备要求：

- 五槽COST可选择1、3、4，总和上限固定为12。
- 每槽可选择主词条，可固定已有声骸。
- 固定声骸列表只显示名称和COST，按对应槽位COST筛选；悬浮可查看完整实例信息。同名物品仍以UUID分别保存，更改COST后不悄悄替换原固定件，冲突需重新选择或解除。
- 目标分默认0，表示不启用门槛。设为正数后，达标角色的目标效用封顶，优先让其他同级角色获得好声骸；高优先级组依然先配装。五件分数仍显示真实总分，不截断评分。
- 允许套装可多选，并设置最少件数；新保存的要求按同套装不同名称计件，五件套需五个不同名称，二件套至少两个。允许不同套装混搭。
- 调整角色顺序和 `=` / `>` 控制独占分配优先级。

点击“确认要求”才保存配装角色的修改；“返回”有未确认修改时会询问是否放弃。匹配角色设置仍实时自动保存。

尚未配置的角色使用XWUID默认配装套装：启动时读取已验证的本地缓存，离线无缓存时使用随包资料（2026-10-16快照，64个角色条目）。启用自动资料更新后会定期从国内资源镜像检查，也可在设置中手动检查；失败继续使用原资料。匹配只带入套装范围；配装同时带入原样本的5件、3+2或1+2+2件数组合。它是资源样本，不保证适合每种模版或队伍；可自行修改。已有手动配置，包括匹配里明确清空的套装，不会被默认值覆盖。资料未收录的角色保持空白，不猜测推荐。更新不修改已打开的配装草稿、已保存或备份的配装；匹配旧结果会失效，需主动点击计算。

设置好所有角色要求后，点击顶部“直接配装”查看结果。“选择声骸”可更换候选；不足时调整要求或继续收录。多角色结果按角色连续分组，每组显示头像、总分评级和五件声骸；上下滚动即可查看全部，点击角色栏只定位到该组，不重新计算。

方案显示每个角色的五件声骸、当前分及总配装评级。搜索有时间/节点预算，预算内最佳结果不代表已证明全局最优。

结果上方的“备份全部方案”仅记录全部角色的冻结备份，允许缺件，不更改装备者、占用或当前配装。“全部设为当前”必须完整五件，通过校验后更新当前配装、声骸占用和工坊装备者。每个角色组的“备份方案”“设为当前配装”只处理该角色。按钮悬浮说明各自影响；都不操作游戏装备。移出参与角色不删除历史或解除当前保护。匹配与配装主页面不设置底部补救按钮；候选不足时使用顶部选择声骸、角色齿轮或声骸库入口处理。

点击角色名和评分后的“变动”，顶部突出旧总分、新总分和涨跌分差，下方紧凑并排比较换下、换上的声骸；只看该角色，不重算或保存。结果卡片右上角的装备者仅显示名字。

已保存配装左侧按角色索引，附保存时间和评分，点击后只展示该角色声骸，每行最多三件。总分与评级紧跟角色名。“当前配装”提供替换优化、解除保护、移除配装；“备份配装”提供替换优化和移除配装，不显示解除保护。原“标记装配”已删除，工坊装备者由设为当前配装统一更新。点击声骸可多选，解除保护只处理选中项；替换优化只接受单选。选择一件后点“替换优化”，可比较同COST候选的分数与总分变化；应用仅产生预览，其他四件固定。当前页点击“更新当前配装”才生效；备份页可“另存备份”保留独立新快照，或明确“设为当前配装”更新占用。原备份不会被预览或另存覆盖。

“备份配装”默认只显示明确执行备份的记录，并标明“手动备份”。“显示保存版本与旧快照”可查看设为当前时生成的版本及旧版记录，均有来源标签，不会冒充手动备份。移除当前配装会释放它的占用，保留独立手动保护和备份；移除备份仅归档所选角色的列表项，不删除声骸、不改当前配装或其他角色，并保留底层冻结证据以免破坏引用。两类移除都需确认，按钮悬浮会说明区别。移除状态随档案导出导入保留。返回按钮回到配装主页面，不覆盖原草稿。

库存变化后，已保存详情会原地重新核验，保留角色与选择；核验失败时点“重新核验”，不需要退出重进。备份和保存都有完成回执；如果只完成历史备份而当前配装更新失败，会分别说明，不要把备份成功误认为当前配装已保存。

### 套装件数选项

- **不要求套装效果**（原“不限件数”）：允许使用这个套装，但不要求至少带几件；可能一件也不选。
- **1件套装效果**：仅在套装资料确有单件效果时提供，与普通散件不同。

旧历史保留原计算规则与分数；重新保存装备要求后采用新的不同名称计件规则。

程序提供手动装备清单，不自动改变游戏装备。

## 设置与档案

在“设置 → 数据”新建、删除、重命名、导入或导出档案。显示名称不影响UUID或关联方案；同名档案可分别存在。

安装更新只替换程序。重装宿主或跨设备时导出档案；档案包包含库存、配装和此档案的匹配/配装配置，不含截图和全局设置。

自动资料更新保留自定义权重。历史方案使用保存时的资料与评级标准，不会被新模版偷偷重算。

设置分为“常用 / 收录 / 计算 / 数据 / 其他”。“数据 → 声骸截图”可确认清理当前工作区所有档案的截图；只删原图，不删声骸数值和配装，已导出的备份不改动。新收录仍会保存截图。

后台在启动、库存变更后以及每五分钟清理一次不再被在库声骸引用的截图，覆盖所有档案并保留待核对记录。历史方案不会单独阻止截图清理；查看已清理的原图会提示缺失，计算和历史分数不变。带图导出自动忽略已清理的图片，不修改原始记录。

“自动检查资料更新”由插件运行时的后台任务每30秒检查到期时间，不依赖打开设置页。首次角色/套装资料约30秒后检查，权重有0～120秒随机延迟；成功后通常24小时再检查。失败按通道退避，权重从5分钟起逐步延长，其他资料通常30分钟后重试，头像按需加载与独立退避。关闭自动检查不会清空缓存；手动检查可随时触发，进行中可取消。

手动检查显示当前步骤、文件或图片计数与耗时。步骤条不是剩余时间估算；各来源网络速度不同，失败切备用可能延长检查。检查不会自动重算现有结果。
