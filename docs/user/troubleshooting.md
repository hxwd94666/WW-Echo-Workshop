# 常见问题

## 插件没有出现

检查完整 `echo-workshop` 文件夹是否位于实际运行目录的 `ok_import/`，不要多嵌套一层，也不要同时保留两份插件。更新后完全退出并重启OKWW。宿主版本与插件适配版本不匹配时，查看宿主日志的加载阶段。

## 选择角色后没有结果

选择或改设置不自动计算。明确选择候选后点击“开始计算”；配装需要先确认每个角色的装备要求。

## 找不到可用声骸或配装

先按页面的具体原因处理：空库先收录、待核对先核对、范围为空重选声骸、固定件冲突到对应角色槽位设置。匹配只展示当前角色可用项；配装还要满足套装件数、五件和独占要求，单件有分不代表整套可行。

## 已保存配装的按钮变灰

库存变化后需要重新核验详情。等待当前核验完成；失败时用“重新核验”。不要重复点击保存来试探状态，也不要清除历史或释放其他角色保护。

## 扫描有失败项

“失败”表示对应声骸未成功入库，不一定在待核对列表里。打开失败位置说明，回游戏重新定位并收录新画面；也可以重新扫描。结束扫描保留已成功收录的数据。

## 分数与游戏表现不同

这是角色模版权重评分，不是伤害模拟。单件与五件评级分别使用对应标准；自定义权重可能改变分数，历史结果使用自己的冻结模版。

## 重装后档案不见了

确认宿主使用的配置/运行目录是否改变。数据位于配置目录的 `plugin_data/echo-workshop/`，不在安装文件夹。不要先清库；可恢复原目录或导入之前导出的档案。

## 资料检查失败

离线或来源暂时不可用时保留内置/已有资料。检查宿主日志的资料通道和错误类型；不要删除缓存来绕过坏数据校验。自定义权重不会因检查失败丢失。

## 操作被取消

正常取消不等于程序错误；已提交数据保留，未完成部分不算成功。确认操作上下文后可重新开始。真实失败会留下阶段和错误类型，报告时使用脱敏诊断。
