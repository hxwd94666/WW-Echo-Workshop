# G5 真实游戏验收清单

以 2560×1440 为发布验收基准；缩放、窗口和捕获切换用于验证坐标与降级，不自动扩大发布范围。离屏运行或合成回放不勾选本清单。

## 前置

- [ ] 在独立宿主或备份后的测试环境安装当前 ZIP，使用临时档案；不覆盖现有库存、设置或旧包
- [ ] 记录 OKWW 版本／提交、ok-script 版本、工坊包版本、捕获器、宿主输入配置、实际工坊输入路径、分辨率及 DPI 缩放
- [ ] 工作台开启“显示实时评分”
- [ ] 设置目标分和评分体系
- [ ] 开启“悬浮窗位置变换”，确认四个 HUD 场景位置
- [ ] 关闭“悬浮窗位置变换”，拖动 HUD，确认不再自动移动

## 实时评分与策略

- [ ] 强化页识别 0–4 条副词条，浮层出现强化建议
- [ ] 五条副词条时出现重抽/锁法建议
- [ ] 切换到联合模式，确认可出联合决策
- [ ] 联合决策为重抽时，测试卡“转到重抽”可用
- [ ] 词条变化时旧结果不冒充新状态

## HUD

- [ ] 背包、单件展示、左右对比、强化／调谐均核对当前分、逐词条位置和翻页后的刷新；对比两侧以同一模版独立评分
- [ ] 切页、换窗、缩放或捕获断开时，旧结果不留在错误页面或窗口；重连后由新帧恢复
- [ ] 锁定后鼠标穿透
- [ ] 详情展开/收起
- [ ] 位置开关关闭后保持手动位置

## 自动战斗兼容

- [ ] 开启自动战斗时插件不抢占采集/OCR 资源
- [ ] 自动战斗不再出现 target_enemy / sleep check 报错
- [ ] 关闭自动战斗后实时评分恢复

## 手动收录

- [ ] 仅开启等待、浏览或切换声骸不写入；一次快捷键最多提交当前一件
- [ ] 背包和展示页各收一件；对比页仅保存右栏的名称、等级、词条和原像素截图；强化／调谐不写入
- [ ] 采样时失焦、切换选中项、切换档案或捕获源、停止后重新开始：旧请求不写入，新请求可以正常收录；普通失焦发生在冻结后时，可继续识别有效截图
- [ ] 核对长／短／括号名称、低等级主词条和套装图标与文字不一致的样本；识别不完整的记录不冒充已核对

## 自动扫描与许可

- [ ] 分别记录原生 SDR WGC、BitBlt 的前台结果；从背包顶部确认等级降序，跨越至少一次滚动，核对重叠行不重扫、新行不漏扫，末页不补造槽位
- [ ] 低等级卡片经选中详情复核后才按阈值停止；仅凭卡片 OCR 误读不提前结束
- [ ] 暂停或失焦后不发输入；同一列表恢复时才能继续。换档案、捕获源、窗口或有效画面边界后，旧扫描不再沿用坐标
- [ ] 停止、关闭或卸载后不再发出输入；已提交项保留，未提交项不进入库存／待确认区，也不留下本次新建的证据 PNG
- [ ] 原生 SDR 不满足前台条件时不发输入；HDR、浏览器／云游戏与自定义捕获不开放自动扫描。未经实机验证的组合保持后台扫描关闭；离线结果与宿主的 PostMessage／Pynput 配置均不作为实测证据
