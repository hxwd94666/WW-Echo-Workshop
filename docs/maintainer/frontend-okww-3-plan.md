# 声骸工坊前端重构方案：新版 OKWW 桌面 Qt

状态：新旧宿主共用一套界面。F1 已收口主题、公共控件和顶部导航，并完成新版 Windows 无游戏验收。本文补充[项目重构与宿主适配方案](refactor-okww-3-plan.md)，不改变当前已安装包的支持范围。

## 1. 要解决的问题

在真实新版 OKWW 窗口中，工坊背景已换成深蓝黑，但卡片仍有灰底，输入框与卡片色阶脱节；已勾选的复选框只剩紫色方块。顶部「工作台 / 匹配 / 配装 / 声骸库」彼此紧贴，选中态和间距受 Qt 原生样式影响。此前离屏截图看起来正常，说明仅核对调色板值、控件几何或独立窗口不足以验收这个问题。

旧实现有三处样式控制权交叠：`CardWidget` 填色以后仍调用原生 `QFrame` 绘制；顶部 `SegmentedWidget` 依赖原生 `QTabBar` 的度量和选中态；复选框的局部 QSS 只覆盖底色，未接管勾的绘制。实际验收以宿主窗口内的最终像素为准，不以离屏色板值代替。

**保留现有工作台及三模式的页面布局。** 配色用已确认的第二张参考图：深蓝黑底、蓝灰分层、浅色正文和紫色强调。顶部四项允许单独调整间距和选中反馈，但保留位置、顺序、名称和路由；不恢复双栏或默认折叠资源项。评分、评级、配装、收录、OCR、HUD、存储和资料格式均不在本轮范围。

## 2. 旧宿主是否继续兼容

先区分宿主版本与框架版本。`ok-script 2.0.17` 已有插件页面注册器，`2.0.8` 仍需要任务卡和独立窗口入口，并带旧卸载兜底。可打开同一业务页，不等于两个宿主有相同的控件度量、绘制次序、缩放或主题。新版起点是我们已用于离线验证的 Windows 桌面组合：OKWW `03632d02`（`v3.8.5-beta.2`）、`ok-script 3.0.6`、`ok-pyside-minimal 6.12.0.post2`。上游 `v3.8.4` 发布说明也记录了 `3.0.6`；正式支持名单仍按候选包实际验证的组合填写，不据版本号推定所有版本都兼容。

| 选择 | 要维护和验收的内容 | 判断 |
| --- | --- | --- |
| 同一界面加薄兼容层 | 页面、导航组件、主题和用例完全相同；差异只在 `adapters/okww/` 挂载、卸载或能力判断。 | **当前采用。** 新版从宿主主题接口取色板，旧版沿用 Qt 色板；两者经过同一套工坊主题和控件。 |
| 重构后的版本仅正式支持新版 Windows Qt | 只维护一套控件和一条正式挂载路径；旧用户继续用已验证的旧候选，或先升级 OKWW。仍须核对旧包回退和数据身份。 | **兼容成本超限时采用。** 避免为了旧入口牺牲新版界面的可预测性。 |
| 同时维护两套界面 | 每次修改都要同步组件、布局、交互及视觉回归；二者还可能对同一用例形成不同操作语义。 | **不做。** 一旦兼容需要第二套控件、布局或主题补丁，即结束该路线。 |

**退出门槛：**如果后续出现必须按宿主版本分叉控件、布局或 QSS，混装完整 Qt 和精简 Qt，或每次都要重复做整套视觉验收的情况，改为仅支持新版，而不是维护两套 UI。旧版能挂载不等于已完成旧版视觉验收，发布只承诺明列且实测的组合。当前没有旧版用户占比证据，不据此估算影响。旧版包须按文件名、SHA-256 和匹配宿主保留；同为 `0.1` 的候选不得用版本字符串区分。

## 3. 一套界面，明确绘制责任

| 范围 | 做法 | 保持不变 |
| --- | --- | --- |
| 宿主装配 | 保留 `adapters/okww/` 的 `create_import_page(parent)`、稳定任务入口和卸载接线。通过现有 `AssistantServices` 注入页面的应用服务和具体能力；若采用新版 kit 控件，宿主 import 和差异接线集中在适配层，页面不直接判断版本。 | 插件 ID、三个任务类、GUI 线程及卸载清理合同。 |
| 外壳与导航 | `ui/shell.py` 只装配共享顶部、模式导航和页面容器。用同一导航组件管理四项的内边距、间距、选中态与焦点，优先评估可满足现有操作合同的新版 kit 控件；否则由一套 Qt Widgets 组件实现，不把局部颜色补丁叠在原生标签栏上。 | 当前路由、模式顺序、焦点可达性、保护未保存编辑及候选草稿的切换规则。 |
| 主题和公共控件 | 在 `ui/widgets/` 集中定义背景、面板、输入、边框、正文、禁用与强调色。一个控件的底色、边框和状态标记由同一绘制路径负责：用 kit 提供的完整组件，或用工坊组件完整绘制。复选框保留原有 Qt 信号及可访问状态，勾选必须有明确勾形。 | 不修改全局应用主题或宿主侧栏，不在各页面散落同义颜色，不依赖未公开的宿主样式选择器来凑状态。 |
| 业务页面 | 先接入工作台的卡片、复选框和按钮；通过验收后再让复用同一控件的设置、匹配、配装和声骸库受益。只有发现直接影响本次目标的绘制冲突才动对应页面。 | 现有内容顺序、间距、单列/双列规则、显式计算、持久化及应用用例。 |

暗色取样：外壳 `#121218`、卡片 `#1B1B23`、输入 `#22222B`、边框 `#34343C`、强调 `#7C5CFF`；带白字的实心主按钮可用略深的 `#7757FA` 以保持正文对比度。浅色保留独立语义配色，不用反相近似暗色。控件颜色要验收最终像素；焦点、勾选、禁用、选中不单靠颜色区分。

继续采用 Qt Widgets 和当前业务服务；不引入 Web 前端、第二个窗口栈或完整 Qt 专用依赖。能复用 OKWW 原生组件就复用组装和交互，但工坊卡片的最终颜色由已选中的单一绘制路径负责，避免宿主和工坊重复给同一控件绘制不同表面。

## 4. 实施与阶段出口

| 阶段 | 实施内容 | 通过条件 |
| --- | --- | --- |
| F0 · 固定视觉基线 | 记录实际包 SHA-256、宿主与框架版本、主题、DPI 和窗口逻辑尺寸。用临时档案在实际 Windows OKWW 主窗口复现卡片变灰、复选框无勾及四项拥挤。截取必要脱敏区域，并记录页面主体的代表控件位置与尺寸。 | 同一环境能对照修前与修后；区分源代码、离屏夹具与实际装入的包。 |
| F1 · 外壳和工作台试点 | 先收口主题、卡片、复选框及顶部导航；保留其他页面和工作台主体布局。给四项独立点击区域、可见焦点和稳定间距。 | 新版暗色表面及勾形与设计一致。浅色往返、窄窗、键盘切换均正常；除导航外，基线控件位置和尺寸不变。 |
| F2 · 验证薄兼容 | 用同一份产物核对旧版插件注册入口与独立窗口入口，运行必要的加载/卸载契约，再按第 2 节门槛确认发布范围。 | 记录实际复用结果与已验证版本；没有并行 UI。只有新版已有替代入口、相关生产调用已迁移、旧包可退时，才删除旧专用分支。 |
| F3 · 候选交付 | 从唯一源码出包，在隔离宿主验证包内入口、资源、实装显示与回退。更新 README、发布说明、最低已验证版本和升级提示；若改为仅新版，在宿主入口报告不匹配，先于运行时或玩家数据初始化。 | 真实主窗口视觉证据和定向测试一致。正式发布前另按 [G5 清单](release-g5-checklist.md) 验收真实游戏，不用视觉结果替代。 |

### 最小验证集

- **真实桌面 Qt，无游戏：**使用实际解包候选。用一个常用宽窗、一个宿主允许的最窄窗口；明暗两态至少各有实机截图，100% 和 125% 缩放各核对一组，150% 在布局余量或字体度量有变化时补测。不必把所有变量做成全笛卡儿积。聚焦顶部四项间距、完整文案、选中态、Tab/方向键路径、勾形及分层颜色。用色板采样和控件几何证明问题已解决，检查一次切换主题和重启。
- **离线回归：**只跑直接相关的宿主加载与卸载契约和导航/主题用例。核对三任务单次发现、工作台可挂载、设置可返回，草稿守卫仍生效；页面切换不触发评分、配装或收录。视觉调整未碰的计算目录不全量重跑。旧版仅在决定保留时追加对应入口与视觉验收。
- **数据与回退：**用临时档案核对升级前后档案/声骸 UUID、当前配装、自定义权重和数据根一致；本轮不改字段与 schema。退出 OKWW 后，只更换安装目录；旧包放到 `ok_import` 之外。若新版宿主与旧包组合未验证，回退用既有可用宿主与旧包配对，不以旧数据备份覆盖当前配置或库存。`ok_import/.plugin-staging/` 中未完成的操作按宿主流程处理，不由样式改造清理。

## 5. F1 验收边界

- 新版：以 `03632d02` OKWW、`ok-script 3.0.6`、精简 Qt 的真实 Windows 主窗口装载测试包；100% 和 125% 两档各测 1440×940 （暗色）和 1200×800（浅色）。工作台布局网格和代表控件的主体相对坐标、尺寸与基线一致；导航独立留出 8 个逻辑像素的间距。检查了标题和输入文字、卡片、按钮以及白色勾形的最终像素。
- 检查鼠标、Tab、Enter、方向键、Home、路由守卫、设置来回切换及退出，关闭后重新启动亦能挂载。测试用隔离档案，不使用实际配置或库存；未启动游戏、未开始收录。
- 旧宿主只保留薄入口，旧版离屏加载契约不视为旧版原生桌面视觉验收。玩家升级数据核对和实机 [G5](release-g5-checklist.md) 是独立的验收项，不由本轮视觉试点代替。

## 6. 真实窗口的可读性复查

F1 后用户指出明暗主题仍有混色，常用文字偏小。本轮保持页面结构、交互和业务用例，补齐公共表单、列表、弹窗、卡片绘制和设置分组样式。嵌入页的手绘控件、评级色和卡片缓存读取所属工坊主题，不再用应用级调色板猜测 OKWW 的明暗模式。设置和已保存配装复用顶部导航控件，不再叠加宿主原生标签轨道。

工坊常规文字以 12 pt 为下限，区块标题 13 pt、页标题 18 pt，同步保留系统 DPI 缩放。说明文字通过对比度建立层级，而非缩小字号；窄窗优先为下拉箭头预留位置、让工作台选项换行。布局仍按原有页面分组，字号变化允许控件的自然尺寸随之调整。

复查范围为工作台、匹配、配装、声骸库和工坊设置的明暗主题；桌面与缩放验证使用隔离宿主与合成库存。游戏内 HUD、真实玩家库存、正式发行版装机及 G5 不由本次试点替代。
