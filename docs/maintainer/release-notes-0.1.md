## 已验证

- 324 个 Python 文件格式、lint、结构检查通过；
- 资源校验通过；
- Rust 原生测试 18 项通过；
- 核心策略、HUD、实时策略、评分预设测试通过；
- 更新回退和原生包清单测试通过；
- 连续两次构建 SHA256 一致；
- OKWW ZIP API 安装和三个入口导入通过；
- 2560×1440 + 125% 缩放下四场景 HUD 已由用户实机确认；
- 本次 HUD 自动定位功能仅承诺 2560×1440；
- 自动战斗期间及战斗结束后 5 秒内暂停实时评分与策略分析，避免抢占战斗采集/CPU；实时触发间隔保持 0.15 秒；
- HUD 锁定/详情/解锁改为无背景图标；解锁时重建窗口以清除鼠标穿透；
- HUD 编辑面板四个开关等距排列，位置变换位于实时评分右侧，选框直接绑定白色 QSS；
- 位置变换在两个入口标注“仅适配2K”；
- 设置页移除重复的资料更新块和自定义权重重复标题，工作台资料更新保留；
- 删除“展开策略详情”和“切换透明悬浮窗编辑”旧快捷键；
- 解锁图标改为透明背景；
- 实时评分默认关闭；开启时提示 OCR 资源冲突，其他 OCR 功能期间请关闭；
- 关闭实时评分后，HUD 位置变换、策略建议、角色/模版和策略参数全部禁用，插件提前退出；
- 实时评分按词条行冻结已结算分数，词条行未变时忽略单帧 OCR 分数抖动；
- 切换声骸导致词条行变化时立即更新，不引入两帧延迟。

## 未验证/不支持

- 1920×1080、1600×900、1280×720 的 HUD 自动定位不作为本次支持范围；
- 实时识别 → 策略 → HUD 的真实游戏链路；
- 头像后台更新和取消更新的真实网络链路；
- 数据源失败时的现场回退。

未完成上述实机验收前，不标记为正式 release candidate。

## 回退

使用安装前 `ok_import_backup` 目录恢复旧插件；不删除 `plugin_data`、玩家库存和权重缓存。

## 已知环境限制

本机 MSVC `link.exe` 无法在安全策略允许的临时路径创建链接临时文件，原生发布构建必须记录 LLD/临时目录环境；这不是 Rust 代码错误。
